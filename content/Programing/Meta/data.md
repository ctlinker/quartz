# Nature Of Data

## Introduction

In the broader sens a data is a singular unit of information. it's shape and form may varie from field & subject. but it's definition is invariant.

In Programming we may talk about :

- string[^4]
- int[^1]
- uint[^2]
- floating-point-numbers[^3]
- boolean[^5]
- struct/object[^6]

In Mathematics we talk about :

- [[vector.md|vectors]]
- variable
- univers
- space
- points

[^1]: All signed integers $[- \infty; 0; + \infty ]$
[^2]: All positive integers $[0, +\infty]$
[^3]: All fractional non integer number $[-\infty,...;0,...;+\infty,...]$
[^4]: chain of characters
[^5]: true or false
[^6]: data structure containing data or behavior related to the said data
